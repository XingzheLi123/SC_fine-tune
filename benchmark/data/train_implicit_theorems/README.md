# train_implicit_theorems

Theorem-implicit mirror of `benchmark/data/train`. Problems, parameters, canonical answers, and surface perturbations are preserved. Reasoning traces use the same mathematical steps but omit explicit theorem-bank statements.

Record count: 480.

Use this split for the ablation where the model sees examples that apply optional stopping, martingale tests, and hitting-time identities without having the theorem statements spelled out in the reasoning.
